# Submission checklist

## Push to GitHub
```bash
cd unemployment-analysis
git init && git add . && git commit -m "Unemployment analysis: trends and COVID-19 impact"
git branch -M main
git remote add origin https://github.com/<your-username>/unemployment-analysis.git
git push -u origin main
```
(Create the empty repo `unemployment-analysis` on github.com first.)
